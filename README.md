## APIs

### Azure Service Bus API
Azure Service Bus provides REST APIs for sending and receiving messages through queues and topics with support for sessions, dead-lettering, scheduled delivery, duplicate detection, and transactions. The management API enables namespace, queue, topic, and subscription configuration.

**Human URL:** [https://learn.microsoft.com/en-us/rest/api/servicebus/](https://learn.microsoft.com/en-us/rest/api/servicebus/)
